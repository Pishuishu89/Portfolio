# Ishaan Das-Basak | Portfolio

React + Vite + Tailwind + Framer Motion. Live at https://pishuishu89.github.io/Portfolio/

## Edit content
Everything (bio, experience, projects, skills, certs) is in `src/data.js`.
Project screenshots go in `public/images/` and reference them by file name. Projects without an image get a generated cover.

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173/Portfolio/
```

## Deploy
Pushing to `main` deploys automatically via `.github/workflows/deploy.yml`
(one-time: repo Settings → Pages → Source: **GitHub Actions**).
